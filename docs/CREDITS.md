# CREDITS.md

Every third-party asset and dependency in FACEPLANT, with its licence
(CLAUDE.md invariant 10). `tests/game/game.test.ts` checks this file against
what is actually in `public/`, so an uncredited asset fails the test run.

---

## Audio

**There are no audio files.** Every sound in the game is **synthesised at
runtime** in Web Audio by `src/audio/sound.ts` — the tape hiss, the drone, the
Wick squeaks, the gulp, the flame-out, the Gate chime, the Crawler skitter, the
flick, the offering, the Procession steps, the yawn and the scare stingers.

This was a deliberate change from SPEC v1.0's "CC0 sounds in `public/audio`":

- nothing to licence, and nothing to get wrong in an audit;
- about a megabyte less to download;
- no possibility of a runtime fetch for a sound file (invariant 1);
- the Wick squeaks can be pitched **per Wick**, so a crowd of them sounds like
  a crowd rather than one clip retriggered eight times.

Everything passes through a master limiter at −6 dBFS, and scare sounds are
given a 30 ms minimum attack (invariant 6).

The wasm runtime is copied and the model is downloaded **once, at setup time**,
by `npm run setup:mediapipe`, into `public/mediapipe/`. At play time both are
served same-origin from the game's own files. No model, frame, landmark or
blendshape ever leaves the device.

## Art

All of it is drawn in code. There are no image files: the Wicks, the Crawlers,
the Moths, the Drips, the ruins, the lantern, the Gate, the candle icons, the
favicon and the result card are vectors and gradients generated at runtime by
`src/render/` and `src/share/resultCard.ts`.

The post-process look (scanlines, chromatic aberration, grain, vignette) is
built from `pixi-filters`' CRT, RGBSplit and OldFilm filters rather than
hand-written shaders.

## Music, scare audio and the Watcher's faces

Nothing here is third-party. The menu theme (`src/audio/theme.ts`, played by
`src/audio/sound.ts`), the Watcher's heartbeat, drone, whispers and scream, and
all five Watcher faces (`src/render/watcher.ts`, palettes in
`src/render/tokens.ts`) are synthesized or drawn in code at runtime. There is no
audio file and no image behind any of them, so there is nothing to attribute.

This is deliberate. Horror reference photography and horror sound effects are
overwhelmingly copyrighted stock (Getty, Adobe Stock, Shutterstock and the
like), which CLAUDE.md invariant 10 does not allow in the game. If a recorded
track or a photographed face is ever wanted, it must be CC0 or OFL, and it must
be listed in this file before it ships.

## Fixtures

`fixtures/faces/*.json` are **synthetic**, generated by
`npm run make:fixtures` from the game's own canonical Assist face. They contain
only landmark coordinates and five blendshape values — never an image, and
never anyone's face. See `fixtures/faces/README.md`.
